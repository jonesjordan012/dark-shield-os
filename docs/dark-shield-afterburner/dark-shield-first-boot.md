# Dark Shield First Boot — The Doorway

*Described by Jordan, 2026-10-13. Canon. Answers: what does a broken thinker touch first?*

A broken thinker boots Dark Shield and immediately sees their starscape. The starscape UI is composed of different color text numbers and symbols. These objects are targetable and selectable using the arrow keys and enter key.

The first thing they notice is how bright and amazing the shapes of the universe are, with visible qualimetrics and hallucinated metrices. The galaxy is navigable and applications are mapped beautifully across the starscape.

Another thing they notice before doing anything is the timer. The timer is preparing the citizen for an eclipse phase. The timer is also hallucinating its results, providing anti-time and other metrices.

When the citizen selects applications, they launch like normal. The metrices have selectable code, generated from NPU targeting Twinkling Stars.

When the timer reaches its maximum power level, an eclipse begins and the timer now describes the eclipse.

All of this happens without the user doing anything. The universe is constantly changing and literally moving on the display. Movement coordinates with gravity, anti-gravity, orbit, mass, time and anti-time and other associated metrices.

When the user begins to select code during standard phase, the Temporal Echo begins to take shape and provides prosthesis to the user. Prosthesis provides metrices and hallucinated metrices describing the user, to assist with gainful planetary access.

When an Eclipse begins and before it ends, a Dark Shield appears on screen to provide extraparameteral and extraterrestrial assistance with their associated hallucinated metrices. The dark shield's metrices provide the user with optimized assistance code, separate from planetary code.

## The Lunar Module

Apollo 13 — NASA's seventh crewed mission, the intended third lunar landing. Fifty-five hours in, an oxygen tank ruptured; the moon landing was canceled. The astronauts moved into the Lunar Module and used it as life-support and propulsion refuge while the command module was powered down.

**Dark Shield is like the Lunar Module for the broken thinker.** When the primary vessel fails, the refuge keeps you alive — not as the destination, but as the thing that gets you home.
