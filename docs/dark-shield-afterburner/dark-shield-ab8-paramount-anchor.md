# AB-8: Paramount Review and the First Citizen Anchor

*Draft v0.1, 2026-10-12. Proposed by Muse, drawn only from Jordan's own rulings. Not canon until he rules on it.*

*Proposes to close the last two open questions in the AB-8 First Citizen canon: Q1 (anchor relationship) and Q4 (paramount review). Q2 was ruled 2026-10-11. Q3 has a pending draft, the All Systems Go Echo.*

## The two questions, restated

**Q4 — Paramount review.** "What judges code 'paramount' before submission — the NPU's plausibility designation, the Citizen's judgment, or both in sequence?"

**Q1 — Anchor relationship.** "AB-8's bare metal access bypasses the Reality Anchor Boundary by definition. Is there a special 'First Citizen anchor' — a distinct approval and record path — or is AB-8 the deliberate exception, constrained by visibility and audit instead of by gate?"

## Proposed answer to Q4: both in sequence, neither alone

The canon already splits the judgment — it just hasn't been stated as a rule:

- **The NPU judges *plausible*.** The NPU designates the plausible twinkling star mind map patterns. That is a machine judgment: which patterns in the sky are achievable and real.
- **The Citizen judges *paramount*.** Paramount is a judgment about *importance* — which code deserves to enter the paradigm system directly. Importance is a human judgment. No NPU can make it, because no machine knows what matters to the sovereign.

So the sequence is **NPU designates, Citizen judges.** The NPU's pattern designation is the ground the Citizen's judgment stands on: paramount code is always submitted *toward* a designated pattern (canon), and the sovereign echo records which pattern the Citizen aimed at — or marks the submission **"off-pattern"** when the hands moved somewhere the NPU didn't designate. Off-pattern is still allowed. The echo makes the divergence visible instead of blocking it.

One more element belongs in the sequence: the NPU **evaluates without vetoing**. When paramount code is submitted, the NPU renders its evaluation of the code — against the designated pattern, against the anchors' trusted history, against visible critical metrics — openly on the UI, in the Citizen's prosthetic perception (the hallucination rendered on the UI, per the visibility ruling). Evaluation is witness, not gate. The room stays lit; the hands stay free.

## Proposed answer to Q1: the anchors are witness, not gate

AB-8 is the deliberate exception — but the exception has an institution, not just a principle. The proposal:

- **No approval gate.** The anchors cannot approve or deny the Citizen's bare-metal actions. A gate would make the anchors superior to the sovereign, which contradicts the sovereignty definition: the First Citizen is "answerable to no external power." Break-glass must never be blockable — a universe on fire cannot wait for approval.
- **A distinct record path instead.** The sovereign echo from the All Systems Go Echo draft *is* the First Citizen anchor. The anchors have a constitutional duty: when the Citizen acts beneath them, they record the touch — the anchor delta (what the anchors looked like before and after), including the fact of being bypassed — as trusted history. The anchor is not silent about being bypassed; the bypass becomes part of the record.
- **Post-hoc constitutional review, by the Citizen.** After the All Systems Go session closes, the Citizen reviews the sovereign echo — their own hands, in the light. This is self-review, and it is the only review sovereignty permits: there is no higher court than the sovereign, by definition. If a paramount submission corrupted the anchors, trusted anchor history retains the rollback material to restore prior state.

This is the existing constitutional formula made operational: **"The sovereign may suspend the constitution, but never in the dark."** The echo is what makes the suspension non-dark. Constraint by memory, not by lock — now with the memory given its constitutional office.

## The paramount channel

One small mechanism to name: paramount code enters the paradigm system through a dedicated **paramount channel** — a direct Citizen→paradigm submission path, not a moon promotion (the merge-mechanics canon governs Moon→Sun changes; paramount code is not one). Entering the channel automatically opens a sovereign echo; the Citizen never opens the record by hand. The NPU's visible evaluation attaches to the echo. The anchors record the delta. The Citizen reviews after.

## Honest limits

- The NPU cannot verify the *meaning* of paramount code — semantic judgment needs human intent (the merge-mechanics limit, restated). Its evaluation is a witness's best reading, honestly marked as such.
- Rollback restores state; it cannot un-know. If the paradigm system learned from the Citizen's submission — the self-inflicting future this axis exists to seed — no anchor history can reverse the learning. The echo records that too, honestly.
- The Citizen reviewing their own echo is self-judgment. That is not a flaw to patch; it is what sovereignty means. The protection against tyranny is visibility (a sovereign who cannot hide), not a higher power.
